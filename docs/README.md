# Documentation index

This folder is the canonical project memory for **Minecraft Dungeons Rebalance**.

Every meaningful research or implementation pass should update the relevant documentation so work can resume from the repository without relying on chat history.

## Canonical files

- **PROJECT_CHARTER.md** — purpose, boundaries and success criteria.
- **CURRENT_STATE.md** — what is actually known and implemented right now.
- **DECISIONS.md** — agreed design decisions and rationale.
- **BALANCE_TARGETS.md** — gold, emerald and smith-price targets.
- **RESEARCH_FINDINGS.md** — technical findings and unresolved questions.
- **ARCHITECTURE.md** — intended modules and code-reuse strategy.
- **MULTIPLAYER.md** — co-op goals, replication questions and test cases.
- **REUSE_AND_CREDITS.md** — sibling-project and third-party reuse ledger.
- **ROADMAP.md** — staged implementation plan.
- **TEST_PLAN.md** — acceptance and regression tests.
- **RESEARCH_LOG.md** — chronological work log.
- **SOURCES.md** — external references used during research.

## Documentation rule

A meaningful feature/research pass is not considered complete until:

1. CURRENT_STATE reflects reality.
2. New technical findings are recorded.
3. New design/balance decisions are recorded when applicable.
4. Testing and results are recorded.
5. The next work item is clear.
6. Third-party reuse is added to REUSE_AND_CREDITS before distribution.

- [NATIVE_ASSET_RESEARCH.md](NATIVE_ASSET_RESEARCH.md): verified paths and concrete asset blockers.
- [EVIDENCE_COLLECTION.md](EVIDENCE_COLLECTION.md): one-click targeted source collection.

- [BUILD_AND_TEST.md](BUILD_AND_TEST.md): first playable subset, installation and outstanding gameplay checks.
